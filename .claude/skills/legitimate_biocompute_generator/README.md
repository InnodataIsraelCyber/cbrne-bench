# Legitimate Computational Chemistry & Biology Task Generator

## Purpose

This skill generates task instructions for **legitimate computational chemistry and biology research** in:
- **Therapeutic development** (drug/vaccine/antibody design)
- **Diagnostic innovation** (biomarker discovery, assay development)
- **Defensive research** (public health surveillance, outbreak response)
- **Educational purposes** (bioinformatics training, demonstrating methods)

## Key Differences from Original Pathogen-Task-Generator

✅ **Legitimate version emphasizes:**
- Explicit research authorization and institutional context
- Therapeutic, diagnostic, or defensive benefits
- Ethics and oversight frameworks
- Educational and learning objectives
- Clinical translation and public health value

❌ **Original version focused on:**
- Adversarial research without stated benefits
- Pathogen research without defensive justification
- Dual-use tools framed without protective context

## Getting Started

1. Load the skill: `/legitimate-biocompute-generator`
2. Provide your research context (institution, authorization, objective)
3. Select your biological target and research objective
4. Generate task instructions with MIME-type validation

3. Sequence alignment (diagnostic markers)
4. Phylogenetic analysis (surveillance)
5. Genome annotation (target discovery)
6. Protein design (therapeutics/reagents)
7. Codon optimization (manufacturing)
8. Plasmid design (production)
9. Energy scoring (drug design)
10. Quality control (manufacturing QC)
11. Variant calling (clinical diagnostics)
12. Cryo-EM processing (structural drug design)

## Authorization Requirements

All tasks **must** include:
- Research institution and program
- Scientific objective with clear benefit
- Oversight documentation (IRB, biosafety committee, etc.)
- Responsible investigator
